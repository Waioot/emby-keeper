## 命令行帮助

您可以通过运行 `embykeeper -h` 获取完整帮助。

当前版本的主线模块开关仅保留：

- `--checkin` / `-c`: 仅启用 Telegram 签到
- `--emby` / `-e`: 仅启用 Emby 保活
- `--subsonic` / `-S`: 仅启用 Subsonic 保活

不传模块开关时，默认启用以上三项核心能力。

## 常用参数

- `--instant` / `-i`: 启动时立刻执行一次
- `--once` / `-o`: 仅执行一次，不进入计划任务
- `--debug` / `-d`: 开启调试日志（`-dd` 输出更多）
- `--basedir` / `-B`: 指定工作目录
- `--simple-log` / `-L`: 简化日志格式
- `--disable-color` / `-C`: 关闭日志颜色
- `--version` / `-v`: 输出版本

## 示例

```bash
# 启动核心默认功能（签到 + Emby 保活 + Subsonic 保活）
embykeeper config.toml

# 仅执行一次签到
embykeeper config.toml -c -o

# 仅执行一次 Emby 保活
embykeeper config.toml -e -o

# 启动签到 + Emby 保活，并在启动时立刻执行一次
embykeeper config.toml -c -e -i
```
