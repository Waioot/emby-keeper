# 日志监控

计划任务运行过程中, 关键的成功或失败信息可以通过您配置的 Telegram Bot 发送给您.

这些日志会直接发送到您自己的聊天中, 也可以在每日您配置的时间推送当日的关键日志.

**注意**: 启动后首次运行, 将不会发送相关日志.

## 开启条件

### Telegram Bot 推送的开启条件

1. 只有定时任务 (不是运行后立刻执行的一次签到 / 保活) 才会发送日志推送.

2. 您需要先创建一个自己的 Telegram Bot, 并拿到 `bot_token` 和接收消息的 `chat_id`.

3. [配置文件](/guide/配置文件#notifier-子项)设置并启用了 `notifier` 配置, 且推送方式设为 `telegram_bot`:

   ```toml
   [notifier]
   enabled = true
   method = "telegram_bot"

   [notifier.telegram_bot]
   bot_token = "123456:ABC"
   chat_id = "123456789"
   ```

4. 如果您要推送到群组或频道, `chat_id` 也可以填写对应的群组或频道 ID.

### Apprise 推送的开启条件

1. 只有定时任务 (不是运行后立刻执行的一次签到 / 保活) 才会发送日志推送.

2. [配置文件](/guide/配置文件#notifier-子项)设置并启用了 `notifier` 配置, 且推送方式设为 `apprise`:

   ```toml
   [notifier]
   enabled = true
   method = "apprise"
   apprise_uri = "bark://hostname/device_key"
   ```

::: tip 提示
使用 Apprise 推送时不需要配置 Telegram Bot。
:::

## 推送方式

### Telegram Bot 推送 (默认)

Telegram Bot 推送是默认的推送方式, 通过您配置的 Bot 将日志发送到您指定的聊天.

使用条件：

- 需要配置 `bot_token`
- 需要配置 `chat_id`

### Apprise 推送

[Apprise](https://github.com/caronc/apprise) 是一个支持多种推送服务的库, 支持包括 Bark、钉钉、微信、邮件等在内的多种推送方式.

配置示例：

```toml
[notifier]
enabled = true
method = "apprise"
apprise_uri = "bark://hostname/device_key"
```

更多支持的服务请参考 [Apprise 官方文档](https://github.com/caronc/apprise).

::: tip 提示
使用 Apprise 推送时不需要配置 Telegram Bot。
:::
